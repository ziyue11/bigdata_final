# C角色工作总结报告

## 一、角色定位与任务概述

根据项目分工，C角色负责**交互式风险预警看板**的开发与交付。核心任务是将B角色输出的分析结果（`data/analysis/*.csv` 及 `risk_event_table.csv`）转化为一个**可运行的、支持多维度筛选联动**的Streamlit网页看板，用于直观展示金融风险的时间趋势、地域分布、主体排行、舆情情绪等关键指标，并支持用户交互探索。

## 三、核心功能实现

### 3.1 数据加载与预处理（`utils.py`）
- 读取 `data/processed/risk_event_table.csv` 作为风险事件明细底表。
- 读取 `data/analysis/` 下的8张统计表：`summary_stats.csv`、`risk_type_stats.csv`、`risk_time_trend.csv`、`region_risk_stats.csv`、`entity_risk_rank.csv`、`sentiment_trend.csv`、`risk_relation_matrix.csv`、`risk_warning_cases.csv`。
- 统一日期格式，处理缺失值，确保数据可被图表函数使用。
- 实现 `apply_filters()` 函数，支持以下**7类筛选器**的联合过滤：
  - 时间范围（日期滑动条）
  - 数据来源（监管/新闻/评论）
  - 风险类型（信息披露、合规、舆情等）
  - 风险等级（高/中/低）
  - 地区（省份）
  - 主体类型（银行/证券/基金/上市公司等）
  - 关键词搜索（机构名称、违规事由、摘要）

### 3.2 图表绘制（`charts.py`）
- 使用 **Plotly** 实现交互式图表，支持悬停显示详情、图例开关、缩放/平移。
- 开发的图表类型（共7类）：
  1. **风险时间趋势图（双轴）**：监管事件+新闻事件+评论热度（左轴）；月度罚金总额（右轴）。
  2. **风险类型分布柱状图**：按事件数量排序，颜色映射平均风险分。
  3. **地区风险排行横向柱状图**：可调整展示Top N（默认10）。
  4. **高风险主体排行条形图**：支持按平均风险分/事件数/罚金额排序，按风险等级着色。
  5. **舆情趋势双轴图**：负面事件比例（左轴）vs 平均情绪分（右轴）。
  6. **主体类型-风险类型热力图**：展示不同机构类型易发风险的交叉分布。
  7. **风险评分分布直方图**：展示当前筛选结果的风险评分直方图，按高中低着色。

### 3.3 看板页面（`app.py`）
- **页面布局**：采用Streamlit的宽屏模式，侧边栏放置筛选器，主区域分为5个标签页（Tab）。
- **顶部指标卡片**：展示总事件数、高风险事件数、累计处罚金额、负面舆情比例（取自 `summary_stats.csv`）。
- **动态联动**：所有图表（除依赖聚合统计表无法联动的部分）均基于筛选后的 `filtered_events` 实时更新。明细表格同步变化，并支持导出为CSV。
- **明细事件表**：展示事件日期、来源、主体、风险类型、等级、评分、处罚金额、摘要、原文链接，支持点击URL跳转。
- **风险预警案例展示**：直接读取 `risk_warning_cases.csv`，展示典型高关注案例及建议行动。

## 四、技术栈与亮点

| 技术 | 用途 | 亮点 |
|------|------|------|
| **Streamlit** | 快速构建Web应用 | 纯Python，无需前端；内置缓存、组件丰富 |
| **Plotly** | 交互式图表 | 悬停信息、自动缩放、图例开关，大幅提升用户体验 |
| **Pandas** | 数据处理与筛选 | 高效数据清洗、聚合、条件过滤 |
| **Plotly Express + Graph Objects** | 高级图表定制 | 实现双轴图、热力图、直方图等复杂图表 |

### 特色设计
- **防御性编程**：针对数据缺失或单点数据场景，添加了提示信息，避免空图导致误解。
- **可扩展筛选**：所有筛选器支持多选，且保留未选时显示全部数据的默认行为。
- **一键导出**：筛选后的事件明细可下载为CSV，便于离线分析。
- **主题配色**：高风险用红色、中风险橙色、低风险绿色，直观区分。

## 五、遇到的问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| `NameError: name 'px' is not defined` | `app.py` 中使用了 `px.pie` 但未导入 `plotly.express` | 在文件开头添加 `import plotly.express as px` |
| 时间趋势图仅显示单点（2026‑06） | B角色生成的 `risk_time_trend.csv` 只有一个月数据 | ①向B角色提出补充历史数据需求；②在图表函数中加入单点数据提示，避免误导用户以为“趋势线”有意义 |
| Streamlit无法加载CSV文件 | 路径错误或文件编码问题 | 统一使用 `pathlib.Path` 定位项目根目录，CSV读取指定 `encoding='utf-8'` |
| 多表联合筛选性能较慢 | 数据量较大（如超过10万条） | 利用Pandas的布尔索引和 `isin` 方法，避免逐行循环；后续可引入 `@st.cache_data` 缓存筛选结果 |

## 七、改进建议与后续工作

1. **数据质量提升**：当前 `risk_time_trend.csv` 仅有2026‑06一个月数据，建议B角色补充更多月份的历史数据，使趋势图具有分析价值。
2. **性能优化**：当风险事件表超过10万行时，可引入Streamlit的 `st.cache_data` 装饰器缓存筛选结果，减少重复计算。
3. **地图可视化**：若时间允许，可增加 `pyecharts` 或 `plotly.express.choropleth` 绘制中国地图热力图，直观展示地区风险分布。
4. **告警机制**：可扩展为自动发送邮件/钉钉通知：当新增高风险事件时触发告警。
5. **移动端适配**：当前布局在手机屏幕上显示不够友好，可增加响应式调整。
